This is my first self-built website, which was mainly implemented using HTML & CSS with just a little JavaScript added.
For this website I first created a screen design, which I then tried to recreate.

Three pages were implemented:
- the home page (index.html)
- the recipe overview page (menu point "REZEPTE")
- the page with the recipe for the strawberry cake (there is a link in the text to this site on the main page)

Clicking on the logo takes you back to the home page. The burger menu is active with the categories "HOME" and "REZEPTE". The other links do not lead to any other pages.

I created the content myself, i.e. I wrote the texts, took the pictures, and created the icons and logos. The website is written in German.
